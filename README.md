# Grunge Rock Landing Page

A high-fidelity, 90s-inspired "Anti-Design" landing page built with modern web technologies. This project features a raw, analog aesthetic with intentional asymmetry, photocopied textures, and "stuttery" motion.

## Visual Features
- **Xerox Glitch Hero**: High-contrast portrait with specific jitter animations and halftone overlays.
- **Scratch-to-Reveal**: Interactive industrial tape strip in the footer that reveals hidden credits.
- **Aura System**: A unique reward mechanism for users who engage with the secret interactive areas.
- **Analog Motion**: Custom `steps()` timing functions used globally to mimic damaged film and failing monitors.

## Tech Stack
- **Core**: HTML5, Vanilla JavaScript, CSS3
- **Build Tool**: Vite
- **Styling**: Modern CSS with SVG filters for textures and distortion.

## Getting Started

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Launch the development server:
```bash
npm run dev
```

### Production
Build the project for production:
```bash
npm run build
```
